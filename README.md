# PREPPER MAP PRO 2.5

Preparación civil, resiliencia territorial, mapas GIS offline y coordinación privada para grupo pequeño.

## Windows
El instalador Windows se construye mediante GitHub Actions como paquete NSIS `.exe`.

1. Abre la pestaña **Actions**.
2. Ejecuta **Build PREPPER MAP PRO — Windows EXE** con **Run workflow**.
3. Descarga el artefacto `PREPPER-MAP-PRO-2.5-Windows-EXE` cuando finalice el flujo.

El ZIP es únicamente un contenedor de descarga de GitHub Actions; dentro está el instalador `.exe`.

Consulta `docs/private-friends-network-v25.md` para el servidor privado, invitaciones y los límites de seguridad.
