# PREPPER MAP PRO 2.5

Proyecto de mapas GIS y preparación civil. Compilación Windows exclusivamente como instalador NSIS `.exe`.

## Obtener el instalador
1. Abre **Actions**.
2. Ejecuta **Build PREPPER MAP PRO — Windows EXE** mediante **Run workflow**.
3. Descarga `PREPPER-MAP-PRO-2.5-Windows-EXE` y extrae el `.exe` que contiene.

El ZIP es únicamente el contenedor obligatorio del artefacto de GitHub Actions; el instalador entregado es `.exe`.
