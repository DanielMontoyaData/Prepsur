# Gobierno de datos y licencias

- Guardar URL exacta, autoridad, nombre de capa, ID, fecha de consulta, fecha de actualización del origen, CRS original y atribución.
- Revisar condiciones de uso antes de redistribuir. La ficha de algunos datos del POT de Itagüí indica que su utilización requiere autorización municipal; no asumir licencia abierta.
- OpenStreetMap: atribuir a colaboradores y cumplir ODbL. No usar tiles estándar de OSM como paquete offline masivo.
- Distinguir datos oficiales, comunitarios, comerciales y observaciones de campo.
- Datos de comercios pueden cambiar; no marcar disponibilidad de inventario ni horario de emergencia sin confirmación.
- Refugio: solo `verified` si autoridad confirma habilitación vigente, capacidad, accesibilidad y periodo de operación.
- Agua potable: no marcar potable por apariencia, proximidad a fuente o comentario comunitario; exigir confirmación del prestador/autoridad sanitaria.
- Solar: separar `solar_power` (hay generación), `public_charging` (existe servicio de carga pública) y `backup_power` (respaldo confirmado).
- Los reportes ciudadanos permanecen `pending` hasta revisión.
