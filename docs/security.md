# Seguridad y privacidad

- Separar vistas públicas y privadas a nivel de API y base de datos, no solo ocultando botones.
- No exponer ubicaciones de domicilios, familiares, inventarios, medicamentos, dispositivos de seguridad ni contactos personales.
- No publicar objetivos de saqueo, armas, municiones, arsenales, depósitos o vulnerabilidades de infraestructura.
- Aplicar autenticación robusta, mínimo privilegio, TLS, copias cifradas, rotación de secretos y auditoría.
- CORS restringido a dominios propios en producción.
- No usar contraseñas de ejemplo en despliegue.
- Revisar reportes de usuarios para evitar datos falsos o maliciosos.
- No usar el sistema como fuente única para decidir evacuaciones.
