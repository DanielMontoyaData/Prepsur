# Puesto de mando local — PREPPER MAP 1.2

## Propósito
Bitácora local para ejercicios, preparación y coordinación interna. Permite crear
incidentes, asignar prioridad P1-P4, registrar municipio, referencia general,
responsable, situación, estado y novedades cronológicas.

## Funciones
- Crear, actualizar y cerrar incidentes.
- Mantener una bitácora cronológica con hora ISO.
- Exportar respaldo JSON e importar respaldos del mismo esquema.
- Guardar datos exclusivamente en localStorage del dispositivo/navegador.
- Límite de 100 incidentes y 500 novedades por incidente.

## Uso responsable
- No es un sistema de despacho ni canal de comunicación de emergencias.
- No transmite alertas, solicitudes de recursos ni órdenes operativas.
- No ingresar contraseñas, información médica, datos de víctimas ni domicilios privados.
- Confirmar los hechos por canales oficiales y registrar fuente y hora en la novedad.
- Para coordinación real, utilizar los sistemas institucionales autorizados.
- Exportar respaldos periódicamente; borrar datos del navegador puede eliminar la bitácora.

## Flujo sugerido para ejercicios
1. Abrir un registro con nombre de ejercicio/incidente, municipio, prioridad y responsable.
2. Registrar hechos confirmados y separar hipótesis de observaciones.
3. Añadir novedades con hora, fuente, decisión y responsable.
4. Actualizar el estado y dejar constancia de transferencia o cierre.
5. Exportar respaldo al finalizar y custodiarlo según el protocolo de la organización.
