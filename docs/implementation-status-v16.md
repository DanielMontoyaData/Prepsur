# PREPPER MAP PRO 1.6 — Estado

## Implementado
- Cribado de activos georreferenciados dentro de un radio de incidente.
- Cruce espacial del buffer del incidente con polígonos de amenaza.
- Distancias métricas, conteos por categoría y áreas de intersección.
- Informe JSON y limitaciones explícitas.
- Validaciones de coordenadas, radio y GeoJSON.

## Pendiente
- Datos oficiales descargados para las seis jurisdicciones.
- Padrón territorial de equipamientos con autorización y metadatos.
- Interfaz gráfica para ejecutar el análisis y visualizar resultados.
- Mapas base regionales offline y binarios firmados de escritorio/móvil.
- Pruebas de campo y validación institucional.

El módulo procesa los archivos que el operador suministre; no incluye ni inventa ubicaciones de activos.
