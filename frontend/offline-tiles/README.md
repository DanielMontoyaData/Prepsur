# Teselas offline

Coloca aquí el resultado de `backend/scripts/mbtiles_to_xyz.py`. Debe existir
`manifest.json` y carpetas `{z}/{x}/{y}.png|jpg|webp`.

No se incluyen teselas por defecto. Usa únicamente datos cartográficos que
tengas derecho a descargar, redistribuir y almacenar. Conserva atribución y
licencia. No hagas descargas masivas desde `tile.openstreetmap.org`.
